# 🎓 学生成绩管理系统 (Student Grade Management System)

本项目是一个基于 Node.js + Express + MySQL 的全栈 Web 应用，主要用于高校教务成绩的管理与统计分析。

## ✨ 核心功能

1. **用户认证**：支持管理员（用户）注册、登录、修改密码。
2. **成绩管理 (CRUD)**：
   - 列表查询：支持按科目动态筛选成绩。
   - 成绩录入：自动关联班级和学生，支持新学生的自动建档。
   - 成绩修改：支持针对单科成绩进行修改。
   - 成绩删除：支持删除错误或过期的成绩记录。
3. **统计分析**：
   - 按班级、科目统计参考人数、平均分、最高分、最低分及及格率。
   - 自动生成并展示“优秀学生名单（>=90分）”与“不合格学生名单（<60分）”。

## 🛠 技术栈

- **前端**：原生 HTML5, CSS3, 原生 JavaScript (ES Module)
- **后端**：Node.js, Express 5
- **数据库**：MySQL 8 (使用 `mysql2` 连接池)
- **安全**：bcrypt 密码加密，express-session 登录态维持

## 🚀 快速启动

1. 安装依赖：

   ```bash
   cd 网站/backend

   ```
